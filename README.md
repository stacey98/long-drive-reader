# Long Drive Reader

A free web app that reads PDFs aloud, made for listening in the car.
Open it at the GitHub Pages address of this repository.

- Skips headers, footers, page numbers, footnotes and citations
- Reads scanned PDFs (text recognition in the browser)
- Optional natural voice (Kokoro-82M, runs on the device)
- Library, bookmarks, sleep timer, car-sized skip buttons

Everything runs in the browser. PDFs never leave the device.

Third-party parts: Kokoro-82M model (Apache-2.0), kokoro-js (Apache-2.0),
ONNX Runtime Web (MIT), Tesseract.js and its English data (Apache-2.0), PDF.js (Apache-2.0).
